# Блок мио-тренажёра для Tilda

Рекомендуемый вариант — iframe опубликованного Vercel-приложения:

1. Откройте в Tilda страницу и добавьте блок **T123 — HTML-код**.
2. Откройте файл `myo-trainer-iframe.html`.
3. Скопируйте код целиком в поле HTML-кода блока вместо старого iframe высотой `9000px`.
4. Сохраните блок и заново опубликуйте страницу.

Высота iframe обновляется автоматически по нижней границе полезного содержимого. После последнего блока остаётся только внутренний отступ приложения, а не фиксированный пустой экран.

Файл `myo-trainer-tilda.html` — резервная автономная версия без iframe.

Данные формы существуют только до обновления страницы.
