# Блок мио-тренажёра для Tilda

Рекомендуемый вариант — iframe опубликованного Vercel-приложения:

1. Откройте в Tilda страницу и добавьте блок **T123 — HTML-код**.
2. Откройте файл `myo-trainer-iframe.html`.
3. Замените `YOUR_PUBLIC_MYO_URL` на адрес приложения в Vercel.
4. Скопируйте код целиком в поле HTML-кода блока, сохраните и опубликуйте страницу.

Высота iframe обновляется автоматически по реальной высоте приложения. После последнего блока остаётся только 28 пикселей воздуха, а не фиксированный пустой экран.

Файл `myo-trainer-tilda.html` — резервная автономная версия без iframe.

Данные формы существуют только до обновления страницы.
