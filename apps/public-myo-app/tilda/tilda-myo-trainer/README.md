# Блок мио-тренажёра для Tilda

1. Откройте в Tilda страницу и добавьте блок **T123 — HTML-код**.
2. Откройте файл `myo-trainer-tilda.html`.
3. Скопируйте его содержимое целиком в поле HTML-кода блока.
4. Сохраните блок и опубликуйте страницу.

Файл автономный: CSS, JavaScript и логотип TFit встроены внутрь. React, npm и загрузка дополнительных файлов не нужны. Данные формы существуют только до обновления страницы.
