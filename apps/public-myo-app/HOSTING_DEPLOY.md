# Размещение мио-тренажёра на обычном хостинге

Приложение собирается в полностью статический сайт. Node.js на хостинге не нужен. Целевой адрес: `https://myo.terentevfit.ru/`.

## 1. Локальная сборка

Откройте Terminal и выполните:

```bash
cd "/Users/iliaterentev/Documents/New project/apps/public-myo-app"
npm install
npm run typecheck
npm run build:hosting
```

Результаты:

- папка `out` — готовые файлы сайта;
- файл `hosting-package.zip` — те же файлы, упакованные без внешней папки `out`;
- файл `tilda-embed.html` — готовый iframe-код для Tilda.

Обычная команда `npm run build` также создаёт папку `out`, но не создаёт ZIP. Если `out` уже собрана, архив можно пересоздать командой `npm run package:hosting`.

## 2. Поддомен и DNS

1. В панели хостинга создайте поддомен `myo.terentevfit.ru`. Раздел может называться «Домены», «Поддомены», «Сайты» или «Добавить сайт».
2. Назначьте поддомену отдельную корневую папку, например `myo.terentevfit.ru`, `public_html/myo` или предложенную панелью директорию.
3. Если DNS домена управляется на этом же хостинге, запись часто создаётся автоматически.
4. Если DNS управляется отдельно, добавьте запись, которую укажет хостинг:
   - обычно `A` для имени `myo` на IPv4-адрес сервера;
   - либо `CNAME` для имени `myo` на технический домен хостинга.
5. Не создавайте одновременно конфликтующие `A` и `CNAME` для одного имени. Обновление DNS может занять от нескольких минут до 24 часов.

Этот порядок подходит для REG.RU, SpaceWeb и Timeweb; конкретные названия разделов панели могут отличаться.

## 3. Загрузка файлов

1. Откройте «Файловый менеджер» или подключитесь по FTP/SFTP.
2. Перейдите именно в корневую папку поддомена `myo.terentevfit.ru`.
3. Загрузите `hosting-package.zip` и распакуйте его в этой папке. После распаковки удалите загруженный ZIP с сервера.
4. Проверьте, что `index.html` находится непосредственно в корне сайта, а не внутри `out` или `hosting-package`:

```text
index.html
404.html
_next/
brand/
icons/
manifest.webmanifest
sw.js
```

Вместо ZIP можно загрузить всё содержимое локальной папки `out`.

Не загружайте `node_modules`, `.next`, исходники `.ts`/`.tsx`, `.git`, `package.json`, конфигурационные файлы или всю папку проекта.

## 4. HTTPS и проверка

1. В разделе «SSL», «Сертификаты» или «Безопасность» выпустите бесплатный сертификат Let's Encrypt для `myo.terentevfit.ru`.
2. Включите перенаправление HTTP → HTTPS, если панель предлагает эту настройку.
3. Откройте `https://myo.terentevfit.ru/` в приватном окне браузера.
4. Проверьте главную страницу, выбор упражнений, таймер, ввод повторений, стоп-сигнал, изображения и видео Kinescope.
5. Дополнительно проверьте `https://myo.terentevfit.ru/manifest.webmanifest` и `https://myo.terentevfit.ru/sw.js`.

## 5. Встраивание в Tilda

1. Откройте `tilda-embed.html`.
2. Скопируйте файл целиком в блок **T123 — HTML-код** вместо старого iframe с Vercel.
3. Сохраните блок и заново опубликуйте страницу.
4. Код принимает высоту только от `https://myo.terentevfit.ru`, поэтому старый адрес Vercel использовать не нужно.

Высота iframe обновляется автоматически при изменении интерфейса и ширины экрана. Если сообщение не будет получено, через 3,5 секунды включится резервная высота.

## 6. Старый service worker и кэш

Service worker привязан к домену. Worker с Vercel не управляет новым поддоменом, но браузер или Tilda могут хранить старую страницу.

После переноса:

1. Замените iframe-код в Tilda и перепубликуйте страницу.
2. Откройте страницу в приватном окне или выполните жёсткое обновление (`Cmd + Shift + R`).
3. Если старая версия остаётся, в DevTools откройте **Application → Service Workers**, нажмите **Unregister**, затем в **Storage** выберите **Clear site data** для соответствующего домена.
4. Очистите кэш страницы в настройках публикации Tilda, если такая функция доступна, и опубликуйте её снова.

## 7. Будущие обновления

После изменения приложения:

```bash
cd "/Users/iliaterentev/Documents/New project/apps/public-myo-app"
npm run typecheck
npm run build:hosting
```

Сделайте резервную копию текущих файлов на хостинге, затем замените их содержимым нового `hosting-package.zip`. `index.html`, `_next` и `sw.js` нужно обновлять вместе. После загрузки проверьте сайт в приватном окне.
