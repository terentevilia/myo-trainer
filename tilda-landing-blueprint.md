# Лендинг для Tilda в стилистике референса

## Базовая концепция

Ниже адаптация под продукт в нише обучения/менторства для занятых специалистов:

- аудитория: middle-специалисты в IT, руководители небольших команд, владельцы малого бизнеса, перегруженные работой люди
- цель страницы: продажа курса / программы с возможностью оставить заявку
- стиль: темный минимализм, премиальная подача, крупная типографика, мягкие синие акценты, clean UI
- принцип: не копировать референс, а взять его настроение: темный фон, большие заголовки, аккуратные карточки, акцент на результат и доверие

## Арт-дирекшн

- фон: почти черный `#0b0d12`
- карточки: `#11141b`
- основной текст: `#f5f7fb`
- вторичный текст: `#a7afc0`
- акцент: `#2f6bff`
- дополнительный акцент: `#78a6ff`
- радиусы: 20-32px
- тени: мягкие, с холодным синим свечением
- сетка: много воздуха, контейнер 1160-1200px
- заголовки: очень крупные, плотные, 700-800
- мобильная версия: укрупненные кнопки, один столбец, меньше декоративных деталей

## 1. Структура страницы по секциям

### 1. Hero / приветственный экран

Задача: быстро объяснить ценность, дать видео и первый CTA.

Состав:

- мини-плашка доверия над заголовком
- крупный заголовок
- подзаголовок
- видео-презентация
- две кнопки: `Смотреть программу` и `Записаться / Купить`
- короткая строка с фактами: формат, длительность, доступ

### 2. Преимущества

Задача: показать, почему программа подходит именно занятым людям.

Состав:

- заголовок секции
- 4-6 карточек преимуществ
- короткий блок с цифрами / результатами

### 3. Как это работает

Задача: снять вопрос "что будет происходить после оплаты".

Состав:

- заголовок
- 3-4 шага
- при желании: вертикальная timeline в стилистике референса

### 4. Структура курса

Задача: показать содержание без перегруза.

Состав:

- заголовок
- подзаголовок
- аккордеон из 6-8 модулей
- внутри каждого модуля: результат, темы, формат материалов

Задача: повысить доверие.

Состав:

- заголовок
- 3-6 карточек отзывов
- можно смешать текстовые отзывы и скриншоты переписок

### 6. CTA + цена

Состав:

## 3. Вариант сборки в Tilda

Ниже практичный вариант: где лучше использовать стандартные блоки Tilda, а где Zero Block.

### 1. Hero

Лучше делать через `Zero Block`.

Почему:

- нужен дорогой первый экран с точным контролем отступов
- можно аккуратно собрать крупный заголовок, плашку доверия, видео и две кнопки
- проще сделать похожее настроение как в референсе

Что внутри:

- фон с мягким синим свечением
- логотип / название продукта
- бейдж с коротким social proof
- заголовок и текст
- HTML-видео или Tilda video block, встроенный в композицию

### 2. Преимущества

Можно делать стандартными блоками.

Рекомендация:

- сетка карточек преимуществ: стандартный блок из категории `Features / Tiles`
- блок с цифрами: стандартный блок из категории `Numbers / Facts`

Когда брать `Zero Block`:

- если хотите нестандартную композицию, например крупное фото + цифры поверх

### 3. Как это работает

Два варианта:

- быстрый и надежный: стандартный блок `Steps / Process`
- визуально сильнее: `Zero Block` с вертикальной timeline

Если бюджет/срок ограничен, лучше стандартный блок.

### 4. Структура курса

Лучше стандартный `Accordion / FAQ`.

Почему:

- быстрее собирать
- удобно редактировать тексты
- нативно адаптируется на мобильных

Если нужно, можно потом докрутить внешний вид через CSS.

### 5. Отзывы

Лучше стандартные блоки.

Рекомендация:

- карточки отзывов: стандартный `Testimonials / Reviews`
- скриншоты переписок: галерея или карточки в 2-3 колонки

Если хотите эффект как в референсе с разной высотой карточек, можно собрать через `Zero Block`.

### 6. CTA + цена

Лучше `Zero Block` или стандартный `Price / Tariff block` + CSS.

Рекомендация:

- если нужна простая реализация: стандартный блок тарифа
- если нужна премиальная карточка с акцентом на цену и две кнопки: `Zero Block`

### Оптимальная сборка по трудозатратам

- `Zero Block`: Hero, CTA/цена
- Стандартные блоки: преимущества, цифры, как это работает, аккордеон, отзывы

## 5. JS для кнопки / таймера / анимации

Вставка в `T123` внутри тега `<script>...</script>`.

```html
<script>
document.addEventListener('DOMContentLoaded', function () {
  var scrollButtons = document.querySelectorAll('[data-scroll-to]');

  scrollButtons.forEach(function (button) {
    button.addEventListener('click', function (event) {
      var targetId = button.getAttribute('data-scroll-to');
      var target = document.querySelector(targetId);

      if (!target) return;

      event.preventDefault();
      target.scrollIntoView({ behavior: 'smooth', block: 'start' });
    });
  });

  var revealItems = document.querySelectorAll('.uc-reveal');

  if ('IntersectionObserver' in window && revealItems.length) {
    var observer = new IntersectionObserver(function (entries) {
      entries.forEach(function (entry) {
        if (entry.isIntersecting) {
          entry.target.classList.add('is-visible');
          observer.unobserve(entry.target);
        }
      });
    }, { threshold: 0.18 });

    revealItems.forEach(function (item) {
      observer.observe(item);
    });
  } else {
    revealItems.forEach(function (item) {
      item.classList.add('is-visible');
    });
  }

  var timer = document.querySelector('[data-deadline]');

  if (timer) {
    var deadlineValue = timer.getAttribute('data-deadline');
    var deadline = new Date(deadlineValue).getTime();

    function updateTimer() {
      var now = new Date().getTime();
      var distance = deadline - now;

      if (distance <= 0) {
        timer.innerHTML = 'Предложение активно сейчас';
        return;
      }

      var days = Math.floor(distance / (1000 * 60 * 60 * 24));
      var hours = Math.floor((distance / (1000 * 60 * 60)) % 24);
      var minutes = Math.floor((distance / (1000 * 60)) % 60);

      timer.innerHTML = 'Цена действует еще: ' + days + 'д ' + hours + 'ч ' + minutes + 'м';
    }

    updateTimer();
    setInterval(updateTimer, 60000);
  }
});
</script>
```

### Как использовать JS

#### Кнопка плавного скролла

Добавьте кнопке атрибут:

```html
<a href="#price" class="t-btn" data-scroll-to="#price">Смотреть цену</a>
```

#### Таймер

Добавьте HTML-элемент в `T123` или `Zero Block HTML`:

```html
<div class="uc-chip" data-deadline="2025-12-31T23:59:00">
  Цена действует еще: ...
</div>
```

#### Анимация появления

Добавьте класс `uc-reveal` нужным карточкам, текстам, колонкам или кнопкам.

## 6. Практическая схема блоков Tilda

Ниже порядок сборки страницы.

### Блок 1. Hero

- `Zero Block`
- видео
- 2 кнопки
- social proof / мини-бейдж

### Блок 2. Преимущества

- стандартный блок карточек на 3 или 6 элементов

### Блок 3. Цифры

- стандартный блок с 3 фактами

### Блок 4. Как это работает

- стандартный `Steps` или `Zero Block timeline`

### Блок 5. Структура курса

- стандартный `Accordion`

### Блок 6. Отзывы

- стандартный `Testimonials`
- при необходимости ниже отдельный блок со скриншотами

### Блок 7. Финальный CTA и цена

- `Zero Block` или тарифный блок
- кнопка оплаты
- кнопка заявки
- дедлайн / таймер

### Блок 8. Форма

- нативная форма Tilda
- короткая форма: имя + телефон / Telegram + кнопка
- подпись: "Свяжемся, чтобы ответить на вопросы и помочь выбрать формат"

## 7. Что лучше подготовить дополнительно перед сборкой

- реальное название продукта
- имя эксперта / автора
- ссылка на видео-презентацию
- 3-6 реальных отзывов
- финальная цена и условия рассрочки
- ссылка на оплату / корзину Tilda
- фавикон, логотип, обложки для карточек

## 8. Короткий вывод по реализации

Если делать быстро и качественно, оптимальная схема такая:

- визуально сложные части через `Zero Block`: первый экран и ценовой блок
- все остальное через стандартные блоки Tilda
- стили и анимации через один `T123` с CSS и JS
- формы оставить нативными

Это даст дорогой внешний вид, нормальную адаптацию под мобильные и быструю поддержку страницы без перегрузки кастомом.
