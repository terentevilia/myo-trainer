# Два изолированных тренировочных приложения

Проект разделён на два самостоятельных Next.js-приложения:

| Приложение | Папка | Содержимое |
| --- | --- | --- |
| Платные программы | `apps/paid-programs-app` | 4 программы, тренировочные дни и журнал |
| Публичные мио-сеты | `apps/public-myo-app` | Только тренажёр мио-сетов, без платных данных |

Каждое приложение устанавливается, запускается и собирается из своей папки:

```bash
cd apps/paid-programs-app
npm install
npm run dev
```

```bash
cd apps/public-myo-app
npm install
npm run dev
```

Проверка каждого приложения:

```bash
npm run typecheck
npm run build
```

## Два проекта на Vercel

Импортируйте один GitHub-репозиторий в Vercel дважды и задайте разные **Root Directory**:

- платное приложение: `apps/paid-programs-app`;
- публичный тренажёр: `apps/public-myo-app`.

В обоих проектах Vercel определит Next.js автоматически. Build command: `npm run build`, Install command: `npm install`. Домены, переменные окружения и доступы настраиваются отдельно.

`public-myo-app` физически не содержит `data/programs.json`, маршрутов `/workout` и компонентов выбора платных программ. Текущий корневой код временно сохранён как резервная рабочая копия и не должен использоваться как Root Directory нового deployment.

## Резервная корневая версия

Ниже сохранено описание исходного объединённого приложения до окончательного подтверждения миграции.

## Что реализовано

- 4 программы: мужские и женские на 2 или 3 дня в неделю;
- выбор программы с сохранением последнего варианта;
- карточки тренировочных дней, статус и дата последнего выполнения;
- карточки упражнений с назначением, разминкой, отдыхом и альтернативами;
- журнал каждого подхода: вес, повторы, RIR, комментарий и отметка выполнения;
- завершение тренировки и простой недельный прогресс;
- отдельная обучалка `/myo-sets` с таймером, логированием и стоп-сигналом;
- PWA manifest, иконки и service worker;
- адаптивный mobile-first интерфейс.

Данные остаются только в браузере текущего устройства. Очистка данных сайта удалит журнал тренировок.

## Структура данных

Исходные CSV находятся в `data/source`. Скрипт `scripts/import-programs.ts`:

1. находит блоки `День N`;
2. пропускает трёхстрочные табличные заголовки;
3. читает упражнения до строки `Комментарий к тренировке`;
4. преобразует повторяющиеся колонки подходов в массив `workingSets`;
5. отбрасывает тоннаж, ошибки формул и служебные расчёты объёма мышечных групп;
6. сохраняет нормализованный каталог в `data/programs.json`.

Статические данные и пользовательское состояние разделены. Назначения лежат в `programs.json`, а состояние имеет версионированный ключ `gym-program:progress:v1` в `localStorage`.

### Мио-сеты

Данные обучающей страницы редактируются в `data/myo-training-day.json`. Состояние хранится отдельно под ключом `gym-program:myo-sets:v1`.

- Изображение: положите файл в `public/exercises/` и задайте, например, `"imageUrl": "/exercises/chest-press.jpg"`.
- Видео: вставьте внешнюю ссылку в `videoUrl`; при пустом значении кнопка не отображается.
- Страница: [http://localhost:3000/myo-sets](http://localhost:3000/myo-sets).

## Локальный запуск

Требуется Node.js 20.9 или новее.

```bash
npm install
npm run import:data
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Проверки перед публикацией:

```bash
npm run typecheck
npm run build
npm start
```

После изменения CSV повторно запустите `npm run import:data` и закоммитьте обновлённый `data/programs.json`.

## Загрузка на GitHub

Создайте пустой репозиторий в GitHub, затем в папке проекта выполните:

```bash
git init
git add .
git commit -m "Initial workout PWA"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

Если репозиторий уже инициализирован, начинайте с `git add .` и не добавляйте второй remote `origin`.

## Деплой на Vercel

1. Войдите в [Vercel](https://vercel.com/) через GitHub.
2. Выберите **Add New → Project** и импортируйте репозиторий.
3. Vercel автоматически определит Next.js. Build command — `npm run build`, install command — `npm install`.
4. Нажмите **Deploy**. Каждый следующий push в `main` создаст новый production deployment.

Переменные окружения для MVP не нужны. Бесплатного Hobby-плана достаточно для этого статического по данным приложения.

## Кастомный домен

1. Откройте проект в Vercel → **Settings → Domains**.
2. Добавьте домен или поддомен.
3. Создайте у регистратора DNS-записи, которые покажет Vercel.
4. Дождитесь подтверждения DNS и выпуска SSL-сертификата.

Не прописывайте DNS «по памяти»: используйте значения из интерфейса конкретного проекта Vercel.

## Установка как PWA

- Android/Chrome: откройте production-сайт и выберите **Установить приложение**.
- iPhone/Safari: **Поделиться → На экран «Домой»**.

Service worker регистрируется только в production-сборке, чтобы кэш не мешал разработке.
